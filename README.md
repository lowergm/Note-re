Note-re

> Não é só um projeto, é uma ferramenta que você pode confiar pra guardar as suas ideias.

O Note-re é um bloco de notas desenvolvido para ajudar você a registrar e organizar suas ideias em um só lugar.

✨ Funcionalidades

- 🔐 Cadastro e autenticação de usuários
- 📝 Criação e visualização de notas
- 🕒 Registro da data e hora de criação
- 🗑️ Exclusão de notas
- 👤 Notas associadas à conta de cada usuário

🛠️ Tecnologias

- Python
- Flask
- Peewee ORM
- SQLite
- Flask-Login
- Tailwind CSS
- Bootstrap Icons

🚀 Planos futuros

- [ ] Permitir que o usuário exclua a própria conta
- [ ] Filtrar notas por data

📌 Sobre o projeto

O Note-re é um projeto em desenvolvimento, criado com o objetivo de ser mais do que um simples exercício de programação: uma ferramenta útil para guardar ideias e consultá-las sempre que necessário.
